# TechInclusiva — Acessibilidade Web e HTML Semântico

-Projeto acadêmico da atividade prática de Acessibilidade Web e HTML Semântico.
-Disciplina: Desenvolvimento para Internet I
-Docente: Profª. Mestre Adriana da Silva Belon

## Arquivos

- `index.html` — estrutura e conteúdo semântico.
- `style.css` — apresentação visual, contraste e estados de foco.
- `TUTORIAL.md` — tutorial passo a passo solicitado na atividade.

## Execução

Abra `index.html` diretamente no navegador. Para uma execução local mais próxima de um ambiente real, também é possível utilizar um servidor HTTP simples.

## Recursos de acessibilidade

- `lang="pt-BR"`
- HTML5 semântico
- Skip link
- Navegação por teclado
- Foco visível
- Texto alternativo na imagem
- `figure` e `figcaption`
- `label` associado aos campos
- `fieldset` e `legend`
- Campos obrigatórios
- Textos descritivos para links e botões
- Contraste visual
